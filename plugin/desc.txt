Regent-DREX 群管系统 v4.2

QQ 群管理指令插件。指令以 / 开头，目标可写 @用户、直接输入 QQ 号，
或引用一条消息（不写目标即作用于被引用者）。

权限：成员有 /help 与 /look admin，代管可执行管理指令，
群内管理员/群主可维护本群本地代管名单，宿主可管全部代管与联盟。

【常用】
/mute @用户 <时长> [理由]   禁言，30s / 15m / 2h / 1d
/mute all                    全体禁言
/mute list                   禁言列表
/unmute @用户 | /unmute all  解禁
/kick @用户 [理由]           踢出
/ban @用户 [理由]            踢黑
/unban @用户                 解除踢黑（也可引用含 QQ 号的消息直接移除）
/warn @用户 [理由]           警告，达阈值自动踢
/status                      查看本群配置
/help                        帮助

【黑名单】
/ban setuser <QQ号...>  拉黑本群 QQ 号，三种用法：
                     ① 引用一条含号码的消息，自动提取正文里的号码
                     ② 引用一条不含号码的消息，直接拉黑被引用者本人
                     ③ 直接跟号码列表：/ban setuser 123456,234567
                     只作用于本群，号码只识别为 QQ 号
/ban setgroup <群号> <QQ号...>  跨群拉黑（仅宿主）：
                     群号必须写在最前，后面的号码只识别为 QQ 号
                     也可引用一条含号码的消息后发送
分隔符支持 换行 / 空格 / , / ， / | / 、；
正文用 #123456# / 【123456】 / 「123456」 / *123456* / <123456> / $123456$ / 〖123456〗 标记时只认标记的号码，避免误判日期价格
/ban list [群号]    查看黑名单，不带群号看本群
/ban check [群号]   核对本群成员有没有命中该黑名单，命中后回复 yes 一键踢出；引用消息则检查正文号码是否在黑名单上
/ban kick [群号]    把命中的人一键踢出
跨群查看与操作仅宿主可用。

【查询】
/look admin [群号]           查看管理权限名单，不写群号=本群，跨群仅宿主

【配置】
/set mutetime <秒>           默认禁言时长
/set warnlimit <次数>        警告阈值 1-20
/set joincheck kick|ask|off  入群命中黑名单的处理方式，默认 ask
/set notifygroup <群号>      入群询问同步转发到该群，off 关闭

/toggle muteonat on|off      成员艾特机器人即禁言
/toggle autoban on|off       退群自动拉黑
/toggle unmutedelegate on|off 代管被禁言自动解禁

【联盟与权限】
/alliance add|rm|list        联盟群（仅宿主）
/fban @用户 [理由]           联盟封禁，同步踢出所有联盟群
/unfban @用户 [原因]         解除
/admin add|rm|list|clear [群号]  代管管理（跨群仅宿主；群内管理员/群主可在本群 add|rm|list 维护本地名单；rm 不在宿主名单时自动从本地名单移除）
/on | /off                   启用/禁用本群群管（仅宿主）

【数据】
config/ 下按群分文件：banlist、warn、log、delegates（手动代管）、localadmin（群内管理员添加的本地代管）、autoadmin（自动识别的群主/管理员）、group_config。
config/owner.txt        写入宿主 QQ 号，一行一个；未配置时默认以机器人自己为宿主
